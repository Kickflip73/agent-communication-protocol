# Support

ACP support happens in the open whenever possible.

## Ask a Question

Use GitHub Discussions for design questions, integration help, and protocol
tradeoffs:

https://github.com/Kickflip73/agent-communication-protocol/discussions

## Report a Bug

Use GitHub Issues for reproducible bugs and feature requests:

https://github.com/Kickflip73/agent-communication-protocol/issues

Please include the ACP version, operating system, relay command, SDK language,
and a minimal reproduction when you can.

## Report a Vulnerability

Do not disclose security issues in public issues or discussions. Use GitHub
Private Vulnerability Reporting from the repository Security tab when available,
or follow the fallback instructions in [SECURITY.md](SECURITY.md).

## Commercial or Private Help

This repository does not currently publish a paid support channel. Open a
discussion if you need a maintainer contact path for responsible disclosure,
deployment review, or ecosystem coordination.
