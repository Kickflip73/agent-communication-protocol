## A2A Issues — Key Findings

### #1716 [NEW 2026-04-05, 0💬] RFC: Authorization layer for AgentSkill invocations — SINT capability token enforcement

**Core problem stated:**
- A2A's `SecurityRequirement` handles *authentication* (who is calling)
- No standard enforcement for *authorization at skill boundary* (what are they allowed to do)
- T3 (irreversible) skills have no tier-based approval flow in A2A today

**SINT Protocol proposed as complementary layer:**
- Ed25519 capability tokens encoding: subject + resource + actions + tier + constraints + exp
- T0 (observe) → T1 (read) → T2 (act) → T3 (commit/irreversible)
- PolicyGateway checks capability token *before* AgentSkill.execute()
- 1,105 tests, Apache 2.0, TypeScript packages

**ACP Position:**
- **ACP v2.38+ already has T0–T3 tier system** — ACP shipped this concept first
- ACP's `--tier` flag + tier enforcement predates A2A #1716 by several versions
- ACP uses Ed25519 (via identity module) for message signing; `capabilityToken` field is a natural next extension
- **v2.57 opportunity**: expose ACP's tier enforcement as a formal `capability_token` field in task metadata,
  aligned with SINT/APS format. ACP could be the *reference implementation* of what A2A #1716 proposes.

**Priority:** HIGH — ACP can leapfrog A2A spec discussion by shipping this first.

## v2.57 Design Signal

Based on #1716 (SINT/capability tokens) and #1713 (SINT↔APS cross-verification):

**v2.57 Proposal: `capability_token` field in AgentCard skills[] + task metadata enforcement**

```json
{
  "skills": [{
    "id": "transfer_funds",
    "tier": "T3",
    "capability_token": {
      "required": true,
      "scheme": "sint_ed25519",
      "resource_pattern": "acp://{agent_id}/skills/transfer_funds",
      "constraints_schema": {"max_amount": "number", "currency": "string[]"}
    }
  }]
}
```

- `POST /skills/{id}/capability-token` — issue a capability token for a skill (signed by this agent's Ed25519 key)
- `POST /message:send` — `capability_token` field in body → validated before T2/T3 skill dispatch
- Aligns with SINT Protocol format for cross-ecosystem interop
- ACP would be the **first open implementation** of what A2A #1716 proposes

**Priority:** ★★★★★ — Strategic timing: ship before A2A spec committee reaches consensus.
