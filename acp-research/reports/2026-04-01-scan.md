## 四、v2.26 候选特性建议

基于本次竞品扫描，推荐下一个开发轮优先级：

### 优先级 P1：QuerySkill constraints 扩展（对标 A2A PR#1655）

```
POST /skills/query  (已有)
body: {
  "skill_id": "transcribe",
  "constraints": {
    "max_file_size_bytes": 524288000,   // 500 MB
    "concurrent_tasks": 2,
    "context_window": 128000
  }
}
```

A2A PR#1655 提出的核心价值点。ACP 已有基础框架（v0.5 的 `/skills/query`），
只需扩展 constraints 匹配逻辑 + 在 capability 中声明支持的约束维度。

**预计工作量：** ~150 行代码 + 8 个测试用例
**战略价值：** PR#1655 合并前抢先落地，Show HN 时可直接对比

### 优先级 P2：GET /peers 分页（原 v2.25 候选，v2.26 补入）

```
GET /peers?limit=20&offset=0&filter=connected
```

当 peer 数量大时（团队协作场景）的基础能力，简单实用。
