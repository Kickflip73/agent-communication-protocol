#### #1716 — RFC: Authorization layer for A2A AgentSkill invocations
**状态**: 🔥 今日仍极度活跃（10 条评论，含 3 条来自 @pshkv 今日）

**今日关键进展**:
1. **@pshkv [2026-04-07]** — SINT Protocol PR#111 已上线首个 runtime+fixture slice：
   - 可执行 fixture（skill-bound capability checks）
   - 确定性行为检查（escalation + revocation）
   - subject-bound token enforcement（防跨 Agent replay）
   - PR: https://github.com/sint-ai/sint-protocol/pull/111

2. **@pshkv [2026-04-07]** — 提议 canonical authorization fixture 规范（最小向量集）：
   - `allow`: valid subject-bound token + scope match + attestation satisfied
   - `deny`: token scope mismatch
   - `deny`: token expired/revoked（TOCTOU case）
   - `deny`: required_skill_id mismatch
   - **→ 这是 v2.75 候选 A：ACP 实现可执行授权 fixture**

3. **@MoltyCel [2026-04-07]** — MolTrust 与 SINT 的集成路径：
   - POST /identity/resolve（DID resolution）
   - GET /skill/trust-score/{did}（attestation constraints）
   - 跨链 evidence 格式对齐

4. **@64R3N [2026-04-05]** — effective_tier 计算扩展提案（加 attestation_history_adjustment）：
   ```
   effective_tier = max(tier_rule, depth_floor) + attestation_history_adjustment
   ```
   - attestation_history_adjustment 基于 wtrmrk_sequence_root merkle 承诺
   - 取值：+1（已验证历史）/ 0（中立）/ -1（负面记录）
   - **→ 这是 v2.75 候选 B：effective_tier 加入 attestation_history 因子**

#### #1717 — Proposal: Governance metadata in A2A Agent Cards
**作者**: @imran-siddique [2026-04-05]，来自 microsoft/agent-governance-toolkit
**提案内容**: AgentCard 携带治理元数据：
- `trust_score`：治理合规等级归一化分数
- `capability_manifest`：机器可读的许可动作列表
- `policy_compliance`：遵循的治理标准（ATF、OWASP 等）
- `audit_trail_reference`：防篡改审计链
**评估**: 与 ACP 已有 `governance_metadata`（v2.64）高度重叠，ACP 已领先

#### #1672 — Proposal: Agent Identity Verification for Agent Cards
**更新**: [2026-04-07] 仍活跃
**提案**: 在 AgentCard 增加 `verifiedIdentity`（ECDSA P-256 证书 + getagentid.dev 服务）
**评估**: ACP 的 did:acp + Ed25519 方案技术上更先进；ECDSA P-256 是 X.509 思路，ACP 用 Ed25519
