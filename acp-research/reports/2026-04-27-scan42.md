## 重要 Issues 新动态（2026-04-26 至今）

### 🆕 #1769 — Verifiable Agent Trust Envelope (VATE)
**最后活跃**: 2026-04-26  
**摘要**: 作者发布了早期草案 VATE v0.1.0（[repo](https://github.com/Poke-nushi/Verifiable-Agent-Trust-Envelope)）。  
**核心问题**：当外部 Agent 要对远程系统执行高风险写操作时，relying party 应在允许操作前验证哪些可移植 artifacts（凭证、权限单、收据）？  
**与 A2A 关系**：VATE 定位为 A2A 的补充（而非替代），专注于信任链与写操作授权。  
**ACP 关联**: 与 ACP 的 capability token + trust signals 体系高度相关，可作为外层授权信封参考。

### 🆕 #1781 — Publish JSON Schema / OpenAPI bundle for Agent Card
**最后活跃**: 2026-04-26  
**摘要**: 社区请求 A2A 官方发布 AgentCard 的 JSON Schema（`$schema` URL），以便工具链验证。  
**核心诉求**：
- 防止工具作者手动复制类型定义（容易漂移）
- 无需解析 TypeScript 源码即可做 IDE 自动补全和 lint
**ACP 关联**: ACP AgentCard 目前也无正式 JSON Schema；此 Issue 若推进，ACP 可同步跟进，提升互操作性。  
**优先级评估**: 中期重要，不阻断当前开发。
