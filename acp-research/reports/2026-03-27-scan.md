#### 1. 原生 Pub/Sub 支持（优先级：高）
A2A PR #1196 展示了将 Pub/Sub 原语引入 Agent 协议的完整设计思路：

A2A SDK v1.0-alpha 引入 AgentCard 的 `supported_interfaces` 字段，明确声明 Agent 支持哪些协议绑定（HTTP、gRPC、JSON-RPC 等）。
- **ACP 建议**：ACP 的 AgentManifest 可增加 `capabilities` 或 `bindings` 声明字段，便于 Agent 发现时的能力协商

#### 3. 数据处理声明扩展（优先级：中）
Issue #1606 的 GDPR 合规需求是企业采用的关键障碍。
- **ACP 建议**：ACP 的 Agent 注册机制可设计可选的 `dataPolicy` 扩展字段，支持企业用户的合规声明需求

#### 4. ClientFactory 模式（优先级：低）
A2A SDK 废弃直接实例化，改用工厂模式，提升了可测试性和扩展性。
