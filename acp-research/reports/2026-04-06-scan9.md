## Issue 动态详情

### #1718 — Bilateral signed interaction records（新增 1 条高价值评论）

**评论者：@aeoess**

核心要点：
1. **APS ↔ TrustChain 集成路径**：双边 IR 记录可作为 APS `update_reputation()` 的可验证证据输入
   ```
   // 当前 APS：self-reported
   { success: boolean, evidenceClass: 'complex' }
   
   // 升级后：counterparty-verified
   { success: boolean, evidenceClass: 'complex', 
     bilateralRecord: { hash, counterparty_key, counterparty_signature, quality } }
   ```
2. **Bayesian 更新增益**：cosigned quality 提供更高置信度 → 更大 sigma 减少
3. **Sybil 抵抗压测**：指出两个真实外部连接良好的 agent 互相刷高 quality 分的场景，MeritRank 是否通过边权重异常检测来处理？

4. **明确请求**（关键！）：
   > "Test vectors for bilateral record verification would be immediately useful. APS could consume them as a reference for `importBilateralEvidence()` — **if you publish a test vector suite, I'll implement the import path against it.**"

   **→ ACP v2.64 的 `/ir/test-vectors` 已经提前交付了这个 test vector suite！**

5. **协议结构建议**：
   - `cosigned_interaction_history` 适合作为 `trust.signals[]` 的新类型
   - 双边记录应作为 A2A 任务完成的**可选扩展**，而非独立协议（保持与 task_id 的紧耦合）

### #1717 — Governance metadata in A2A Agent Cards（新增 1 条评论）

**评论者：@aeoess**

核心要点：
1. **Live governance endpoint 模式**（APS 生产实践）：
   - Agent Card 携带 `serviceEndpoint` → 接收方实时查询当前 trust profile
   - APS 实现：`passportToAgentCard()` → `card.extensions['agent-passport'].serviceEndpoint`
   - 端点返回：grade（0-3）、active constraints、delegation chain hash、behavioral continuity score
   - JWS 签名，接收方用 gateway JWKS 验签

2. **capability_manifest 的正确语义**：
   - 不是"agent 能做什么"（skills 已有）
   - 而是"agent **被授权**做什么"（delegation scope ceiling）
   - APS 用 `scope` 数组作为 capability manifest

3. **policy_compliance 应是可验证引用**：
   - 自声明 "comply with OWASP" 无意义
   - 应链接到签名 attestation 端点（含评估时间戳、policy hash、constraint vector）
   - Schema 参考：`governance-attestation-schema.md`

**→ ACP v2.64 的 `governance_metadata.live_endpoint` 已对齐此模式！**

### #1694 — Add 'limitations' field to AgentCard（新 issue，10 条评论）

**首次出现在扫描视野中。**

核心提案：在 AgentCard 加 `limitations` 字段，声明 agent 的能力边界（rate limits、context window、语言支持、不支持的操作等）。

当前 AgentCard 只声明"能做什么"，不声明"不能做什么"。@kaligautier 提出：
```json
{
  "limitations": {
    "max_concurrent_tasks": 5,
    "rate_limit": "100req/hour",
    "unsupported_operations": ["streaming", "multimodal"],
    "context_window": 128000,
    "supported_languages": ["en", "zh", "fr"]
  }
}
```

**→ 潜在 v2.65 方向：`AgentCard.limitations` 字段**
