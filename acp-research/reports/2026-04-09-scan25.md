## 重点分析

### #1717 — aeoess SDK v1.37.0 Derivation Governance（新发布）

**三个新 governance 原语（2026-04-08）：**

1. **Derivation Rights on Delegations**
   - `derivation_rights: { retention_permitted, retention_ttl, derivation_classes, export_permitted }`
   - 附加到现有 delegation 对象；控制被授权方可从数据访问中 derive 和 retain 什么

2. **CredentialLifecyclePolicy on GovernanceArtifact**
   - `{ maxSessionDurationSeconds, revocationEndpoint, credentialTTLSeconds, revocationCheckFrequencySeconds }`
   - `validateCredentialLifecycle(policy, currentTime)` → `{ valid: bool, reason?: str }`
   - 关闭「session 关闭但 credential 仍存活」的 3-state TLA+ 反例

3. **Recency-weighted evidence scoring（讨论中）**
   - 45天半衰期适用于 imported scores，扩展到 evidence levels
   - `lastVerified` 添加到 attestations

**ACP 对比分析：**
- ACP 已有 `governance_metadata` + `policy_compliance[]`（v2.85）
- ACP delegation chain 有 `expires_at` 字段，覆盖了 CredentialLifecyclePolicy 的核心场景
- **差距**：ACP 没有 `derivation_rights`（retention/export 控制）；没有 `revocationCheckFrequencySeconds`
- **差距**：ACP evidence scoring 无时间衰减（recency weighting）

**P1 建议：** RFC-003 中加入 `derivation_rights` 字段（GDPR 扩展的天然落脚点）

### #1716 — pshkv Canonical Authorization Fixture

**提案（2026-04-07）：** 为 `AgentSkill` 检查定义 canonical authorization fixture：
```
allow: valid token + scope match + attestation satisfied
deny:  token scope mismatch
deny:  token expired/revoked (TOCTOU)
deny:  required attestation missing for high-risk skill
```
输出契约：`effective_tier / decision(allow|deny|escalate) / reason_codes[] / evidence_ref`

**参考实现：** sint-protocol PR#111 — 已交付 runtime+fixture slice

**ACP 对比：**
- ACP 已有 capability token（v2.57）+ effective_tier（v2.67）+ revocation（v2.78）
- ACP `test_effective_tier.py` 覆盖了 allow/deny 场景，但**没有 TOCTOU 场景测试**
- **差距**：TOCTOU（token issue 到 execution 期间发生 revocation）测试用例缺失

**P2 建议：** 在 `test_effective_tier.py` 或新建 `test_capability_toctou.py` 添加 TOCTOU 测试场景
