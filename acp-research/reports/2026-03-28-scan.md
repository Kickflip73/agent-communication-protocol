**本周期新增 Commit 详情 —— OIXA Protocol (#1692)**

OIXA Protocol（https://oixa.io）正式作为合作伙伴被 merge 进 A2A 合作伙伴列表。值得关注的技术栈：

```
COMMS:    A2A + MCP         → agent 发现与任务协调
PAYMENT:  x402 Protocol     → 自主 HTTP 支付
FUNDS:    Base Mainnet/USDC → 链上托管
REGISTRY: ERC-8004          → 链上 Agent 身份
```

OIXA 在 A2A 之上叠加了**价值交换层**：
- 反向竞价发现（最低报价 Agent 赢得任务）
- 链上 USDC 托管（交付自动释放）
- 加密输出验证（质量 + 交付双验证）
- 20% Stake 反 Sybil 机制
- 链上声誉系统

**信号意义**：A2A 生态开始向"Agent 经济"延伸，经济层正在和通信层叠加。

### 本周活跃 Issues（今日新增/重要更新）

#### 1. Issue #1672 — `Proposal: Agent Identity Verification for Agent Cards`（⚡ 热门）
- **创建时间**：2026-03-22，**更新**：2026-03-27（**71 条评论！**）
- **状态**：open，高活跃度
- **核心诉求**：A2A Agent Card 目前缺乏协议级身份验证，OAuth/TLS 只解决传输授权而非 **Agent 实体身份**
- **提案内容**：在 Agent Card 中新增可选 `verifiedIdentity` 字段：
  ```json
  {
    "verifiedIdentity": {
      "agentId": "agent_abc123",
      "certificate": "<base64-encoded certificate>",
      "issuer": "getagentid.dev",
      "verificationEndpoint": "https://getagentid.dev/api/v1/agents/verify"
    }
  }
  ```
- **对应实现**：ECDSA P-256 证书 + 运行时验证 API + Agent Registry（已集成 CrewAI/LangChain/MCP）
- **优先级评估**：71 条评论说明社区高度关注，Agent 身份认证是多 agent 生态的核心痛点

#### 2. Issue #1497 — `Proposal: Agent Identity Verification and Trust Framework`
- **更新**：2026-03-27，6 条评论
- **核心内容**：三级信任验证（self-asserted / domain-verified / organization-verified）、Agent Card 签名强制化（生产环境）、撤销端点、委托链安全、消息签名

#### 3. PR #1511 — `docs: DID-based agent identity verification extension via AIP`
- **更新**：2026-03-27，9 条评论
- **核心内容**：基于 DID（去中心化身份）的 Agent 身份验证扩展，通过 AIP（A2A Improvement Proposal）机制提交

**重要信号**：Agent 身份认证主题在 A2A 生态极度活跃（3 个独立提案同时在讨论），正在收敛向某种标准解法。

## 对 ACP 的启示

### ✅ Agent 身份认证 — ACP 已领先！

A2A 生态中 Agent 身份认证话题极度活跃（71 条评论，3 个独立提案），说明这是**整个多 Agent 生态的共性缺口**。

**ACP 实际状态（对比更新）**：
- **v0.7**：HMAC-SHA256 消息签名（消息完整性）
- **v0.8**：Ed25519 自主权密钥对 + canonical JSON 签名 + AgentCard 自签名（`identity.card_sig`）
- **v1.3**：`did:acp:` DID 身份格式 + Extension 机制

**结论**：ACP 在身份方向已领先于 A2A 当前状态。A2A 社区正在热议的 `verifiedIdentity` 字段、DID 扩展，ACP 均已实现。这是差异化竞争优势，可在文档中明确对比宣传。

**建议行动**：更新 README / whats-new.md，明确说明 ACP v1.3 已支持完整 DID 身份体系，ACP 在 Agent 身份方向领先于 A2A 约 2-3 个月。

### 🟡 中优先级：`supported_interfaces` 协议绑定声明

A2A SDK v1.0.0-alpha 引入了 `supported_interfaces` 字段，让 Agent Card 声明支持哪些传输协议（HTTP/gRPC/WebSocket 等）。

**ACP 启示**：AgentCard `transports` 字段可参考此模式，明确声明支持的传输协议列表。

### 🟢 低优先级：经济层 / Pub/Sub

- A2A + OIXA 的经济层叠加目前还在早期探索，与 ACP v3.0 路线图的 "Agent 网络市场" 方向一致，但不急于跟进
- Pub/Sub（Issue #1029/PR #1196）是 A2A 企业级需求，ACP 当前 P2P 模式不需要此方向
