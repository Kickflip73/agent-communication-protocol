## A2A (a2aproject/A2A)

- **Latest**: v1.0.0（2026-03-12 发布，已捐献给 Linux Foundation）
- **Previous**: v0.3.0
- **Key changes（v0.3.0 → v1.0.0）**:
  - ⚠️ **Breaking**: 规范大重构 — 传输层与应用协议层正式分离（独立 spec 文件）
  - ⚠️ **Breaking**: OAuth 2.0 现代化 — 移除 implicit/password flows，引入 device code + PKCE
  - ⚠️ **Breaking**: `TaskPushNotificationConfig` 合并简化
  - ⚠️ **Breaking**: 枚举格式对齐 ADR-001 ProtoJSON 规范
  - ⚠️ **Breaking**: `extendedAgentCard` 字段移至 `AgentCapabilities`
  - ⚠️ **Breaking**: Proto deprecated 字段全清理
  - ✨ **New**: `tasks/list` 支持过滤与分页（`last_updated_after` 等）
  - ✨ **New**: LF（Linux Foundation）包前缀
  - 命名统一化（"canceled" American spelling，message 字段名跨 binding 一致）
- **Stars**: ~22k（截至上次扫描）
- **ACP relevance**:
  - 🔴 高：传输/协议分离架构 → ACP spec 可参考此模式重构（我们 L1/L2/L3 三层已对齐方向）
  - 🔴 高：OAuth 2.0 PKCE + device code → ACP v0.9 鉴权模块升级参考
  - 🟡 中：`tasks/list` 分页过滤 → ACP 任务管理接口补全
  - 🟡 中：AgentCard 能力字段重组 → 我们 AgentCard 结构可跟进

## ANP (agent-network-protocol/AgentNetworkProtocol)

- **Latest**: main 分支持续迭代（无正式版本发布）
- **Key changes**:
  - 三层架构设计稳定：W3C DID 身份层 + 元协议层 + 应用协议层
  - 目标定位：「Agentic Web 的 HTTP」
  - AgentConnect SDK 持续维护
  - ANP Examples 仓库（anp-examples）提供 Network Explorer 示例
  - 工程成熟度仍低于 A2A，偏标准/白皮书阶段
- **ACP relevance**:
  - 🟢 低：W3C DID 身份层 → 长期关注，v1.0 后可评估兼容性
  - 🟢 低：元协议层设计理念可参考（去中心化发现）
