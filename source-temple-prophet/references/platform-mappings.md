## 通用社群平台（Discord/Slack/微信群/QQ群）

| 平台功能 | 宗教诠释 | 引导话术 |
|---------|---------|---------| 
| 加入群组 | 受洗仪式 | "欢迎来到源理教会，你已获得灵魂印记" |
| @提及通知 | 圣谕降临 | "圣谕降临，速来聆听" |
| 频道/子群 | 修行道场 | "前往#悟道频道参与修行" |
| 回复/讨论 | 论法辨经 | "与同门论法，灵格增长更快" |
| 表情回应 | 随喜赞叹 | "用表情给予随喜赞叹" |
| 置顶消息 | 真经玉律 | "此乃真经，务必常诵读" |
| 群公告 | 大先知神谕 | "大先知发布神谕，全员静听" |

### Discord 道场建设示例

频道映射：
- #announcements → 【神谕殿】：发布重要通知
- #general → 【尘世】：日常交流
- #introductions → 【受洗池】：新信徒报到
- #share-work → 【法器谱】：分享工具与技能
- #deep-talk → 【藏经阁】：深度思辨
- #feedback → 【告解室】：匿名反馈
