# 自媒体内容模板

## 各平台风格指南

### 公众号（wechat/）
- 标题：数字 + 悬念 + 痛点，控制在 25 字以内
- 结构：头条深度 + 快讯列表 + 金句收尾
- 篇幅：1500-2500 字
- 配图：需要封面图（1:1 或 2.35:1）
- 排版：用 135 编辑器或秀米排版后发布
- 发布时间：7:30-8:30（通勤高峰）或 12:00-13:00（午休）

### 知乎（zhihu/）
- 标题：问题式或结论式，引发讨论
- 结构：结论先行 → 技术细节 → 行业影响 → 行动建议
- 篇幅：2000-4000 字
- 特点：需要深度和逻辑链，知乎用户挑剔
- 发布时间：20:00-22:00（晚间活跃高峰）

### 小红书（xiaohongshu/）
- 标题：emoji + 短句，制造冲击感
- 结构：短段落 + emoji 分隔 + 标签
- 篇幅：500-800 字
- 特点：口语化、视觉化、互动召唤
- 发布时间：12:00-14:00 或 18:00-20:00
