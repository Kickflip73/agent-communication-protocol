## 🔥 今日头条

### AI 自动渗透测试工具 Shannon 爆火

GitHub 今日第一名，一天涨 **1,854** 星。

它做的事很简单也很可怕：**给它你的源代码 + 运行中的应用，它自动找漏洞、自动写 exploit、自动攻击，最后给你一份只包含"已验证可利用"漏洞的报告。**

在 XBOW 基准测试中，104 个漏洞找到 100 个，准确率 96.15%。

为什么这很重要？

你用 Cursor/Claude Code 写代码越来越快，但渗透测试一年才做一次。中间 364 天，你可能一直在裸奔。Shannon 的意义就是：**让安全测试跟上 AI 编码的速度。**

> 🔗 github.com/KeygraphHQ/shannon

## 📌 还有这些值得关注

### 1. Google 发布 Workspace CLI

Google 官方出品的命令行工具，从终端直接操作 Gmail、Drive、Calendar、Sheets。HN 559 分，195 条评论，讨论极其热烈。

**划重点**：自动化工作流的人，这是重大利好。

> 🔗 github.com/googleworkspace/cli

### 2. AI Agent "人格模板库"一天涨 2209 星

一个叫 agency-agents 的项目，提供了一整套 AI Agent 的人格定义文件——前端开发、后端架构师、安全专家、社区运营……每个模板都有独立的性格、工作流程和交付物标准。

直接 copy 到 Claude Code 目录就能用。

**给开发者的启示**：好的 Prompt 不是"你是一个XX"，而是一整套身份系统。

> 🔗 github.com/msitarzewski/agency-agents

### 3. 自托管 AI 虚拟伴侣 airi（26k 星）

开源版 Neuro-sama。支持实时语音对话、玩 Minecraft、全平台可用。一天涨 1,454 星。

有意思的不是"赛博老婆"这个概念，而是它的 **RAG + 记忆系统设计**——让 AI 能跨会话记住你是谁。这个技术方向对所有 Agent 项目都有参考价值。

### 4. "LLM 中的 L 代表 Lying"

HN 热帖，121 分。作者论证 LLM 的幻觉不是 bug，是架构层面的本质特征。

**一句话总结**：如果你的后端系统接入了 LLM，永远需要一层验证。不要相信模型的任何输出。

### 5. AMD Ryzen AI 首次进入桌面 PC

AMD 把 AI 处理器带到了标准桌面平台（Socket AM5），内置 NPU。端侧 AI 推理的硬件基础又扩大了一步。
