# Code of Conduct

## Our Pledge

We want ACP to be a practical, welcoming protocol project for people building agent systems. Contributors and maintainers are expected to keep discussions respectful, technical, and generous in interpretation.

## Expected Behavior

- Be clear, kind, and constructive.
- Critique ideas and code, not people.
- Assume good intent, and ask for clarification before escalating.
- Respect maintainers' time by providing reproducible reports and focused pull requests.

## Unacceptable Behavior

- Harassment, discrimination, threats, or personal attacks.
- Publishing private information without permission.
- Sustained off-topic disruption in issues, discussions, or pull requests.
- Bad-faith security disclosures or exploit publication before maintainers can respond.

## Enforcement

Maintainers may moderate, edit, or remove comments; close issues; block accounts; or take other reasonable action to protect the project community.

Report conduct concerns by contacting repository maintainers privately or by using GitHub's platform reporting tools.
