## 下午 — hx-revenue Skill 扩展：档口关键指标查询

### 踩坑记录（重要）
1. **`TO_DATE` 不接受格式参数** → 改用 `CAST(CONCAT(SUBSTR(acceptance_date,1,4),'-',SUBSTR(...)) AS DATE)`
2. **合同表存在大量重复记录**（同一 contract_id 出现10次）→ 全程使用 `DISTINCT`
3. **`latest_expire_date` 为未来时间**（合同未到期）→ 用 `LEAST(latest_expire_date, UNIX_TIMESTAMP())` 截断到今天
4. **合同时间区间存在重叠**（Stark 先生确认需去重合并）→ 使用 island 合并算法（窗口函数实现）

### 最终 SQL 核心逻辑
- 结束时间 = `LEAST(latest_expire_date, UNIX_TIMESTAMP())`
- island 合并算法去重叠：`MAX(end_ts) OVER (...) → is_new_island → grp → MIN/MAX 合并`
- 在租天数 = `SUM(DATEDIFF(FROM_UNIXTIME(merged_end), FROM_UNIXTIME(merged_begin)))`
