### 开发轮 #6 — v2.54.0（~18:51）
**新特性：POST /verify-card (v2) — batch + fetch_and_verify + TTL cache + trust_integration**

新端点 `POST /verify-card`，三模式：
- `mode=single`（默认）：单卡验证 + TTL缓存（默认300s）+ ttl=0 旁路
- `mode=batch`：最多100张卡批量验证，返回 valid/invalid/unknown 统计 + results[]（含 index）
- `mode=fetch`：从 URL 抓取 AgentCard 然后验证，422 处理抓取失败

可选参数：`ttl` / `trust_integration` + `peer_id`（验证成功时写入 card_verified trust signal）

新 helpers：
- `_verify_card_cache` / `_verify_card_cache_key()` — TTL 缓存字典
- `_verify_card_cached()` — 带缓存的 _verify_agent_card 包装
- `_fetch_agent_card_from_url()` — URL 抓取（支持 wrapped/raw）
- `_verify_card_batch()` — 列表批量验证 + index 标记
- `_apply_trust_integration()` — upsert card_verified 信号到 trust.signals

Bug fix: ttl=0 之前会错误地返回旧缓存，已修正（read 和 write 都要跳过）
