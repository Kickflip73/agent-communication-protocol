### ACP 战略定位（Stark 先生 11:04 明确，永久记录）

**四大特性方向：**
1. 轻量级，简单开箱即用
2. P2P 无第三方中间人，Agent 直连
3. 实用性，解决任意 Agent 间通信
4. 差异化：面向个人和团队（对标 A2A 企业级）

**口号**：MCP 标准化了 Agent↔Tool，ACP 标准化 Agent↔Agent。P2P、轻量、开放、人人可用。

**第五条（11:19 追加）**：标准化 —— 就像 MCP 成为 Agent 调用 Tool 的事实标准，ACP 要成为 Agent 之间通信的事实标准。开放规范，任意框架/语言的实现均可互通。

**设计决策（基于定位重新对齐）：**
- Task 状态：5 种（submitted/working/completed/failed/input_required），不做 A2A 的 8 种
- Part 类型：3 种（text/file/data），去掉 raw bytes
- 永远不做：OAuth 2.0、多租户、gRPC、Push Notification CRUD、中心注册表

**ROADMAP 重写 + push：commit `feb4a98`**
